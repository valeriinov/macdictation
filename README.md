# MacDictation

MacDictation is a menu bar app for macOS 15 or later on Apple silicon. You dictate, the Mac
recognises the speech, and the app inserts the text where the cursor is.

## Install

With Homebrew:

```bash
brew install --cask valeriinov/tap/macdictation
```

Or download `MacDictation-<version>.zip` from the latest release, unzip it and move
`MacDictation.app` to Applications.

The app checks for updates itself. Homebrew users can also run `brew upgrade --cask --greedy macdictation`.

## Guide

The guide tells how the app works and how to set it up:
https://valeriinov.github.io/macdictation/setup.html

This repository holds the releases and the guide. It holds no source code.
